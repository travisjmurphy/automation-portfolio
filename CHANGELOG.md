# Changelog

## 1.0.0 — November 10, 2026

### Added

- **Shopify Snapshot Compare:** product and variant comparisons, filters, detailed change inspection, snapshot metadata, and CSV/HTML reports.
- **Transcript Clip Planner:** SRT/WebVTT import, consecutive cue selection, ordered clip plans, editorial notes, local autosave, Markdown/CSV handoffs, and JSON backups.
- **Canadian Permit Explorer:** JSON/CSV import, record filtering and inspection, source attribution, partial-coverage notices, and filtered exports.
- Independent Vite/React/TypeScript packages with lockfiles, tests, sample inputs, and example outputs.
- A bounded official Calgary sample with retrieval metadata and data attribution; fictional samples for the other demonstrations.
- MIT application licence, contribution guide, data-licence notices, and verification documentation.
- A GitHub Actions workflow for installing, testing, and building each app independently.

### Updated

- Portfolio and profile READMEs to feature the application source and demos.
- Canadian permit case study to reflect the Actor's documented 19-municipality coverage.
- Make lead-intake documentation with a workflow diagram and illustrative fictional inputs.

### Release scope

The applications process files locally in the browser. This version does not add live Actor calls, automatic refresh, outbound messaging, video transcription, or video rendering. The Make blueprint must be exported from the tested scenario before it can be supplied as an importable template.
