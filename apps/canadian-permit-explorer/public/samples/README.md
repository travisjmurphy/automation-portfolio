# Importable sample files

- **official-permits.json** — real, bounded Calgary snapshot: 40 records retrieved November 10, 2026. Normalized directly from the official API, not from an executed Actor run. Source query and attribution are embedded.
- **fictional-permits.json** — 38 invented records across 19 municipalities, with synthetic metadata.
- **fictional-permits.csv** — the same invented records in CSV format. Every source and permit ID identifies them as examples; the `synthetic` column also marks each row.

Use the app's **Sample data** button for built-in choices, or **Import data** to load a file. See [data provenance](../../docs/DATA_PROVENANCE.md) for sources and terms.
