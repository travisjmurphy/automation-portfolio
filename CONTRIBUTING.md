# Contributing

Each application is an independent React/TypeScript project under `apps/`.

1. Open the application's directory and run `npm ci`.
2. Run `npm test` and `npm run build` before opening a pull request.
3. Describe the problem, the resulting behavior, and how you checked it.

Useful issue reports include the application name, browser, expected result, actual result, and a small fictional input that reproduces the problem. Do not attach private transcripts, credentials, or customer exports.

The first releases focus on local file workflows. Proposals for accounts, hosted storage, paid AI integrations, or scheduled collection should explain the user need before expanding the architecture.
